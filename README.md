# RunForum

Общаемся на любые темы

Форум работает на GitHub Pages: https://goharchik.github.io/RunForum/

- Темы и ответы — Issues этого репозитория, «спасибо» — реакции 👍.
- Разделы участников — issues с пометкой `type: section`.
- Настройки (название, основные разделы, блокировки) — `forum-config.json`.
- Код форума — `index.html`.
- Картинки администратора — ветка `media`.
